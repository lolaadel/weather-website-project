# Weather App ☀️

A responsive weather application that allows users to search for any city and view its current weather conditions and upcoming forecast.

## 🌐 Live Demo

[View Weather App](https://lolaadel.github.io/weather-website-project/)

## ✨ Features

- Search for weather information by city name.
- Display current weather conditions and temperature.
- Show humidity, wind speed, and wind direction.
- Display the weather forecast for the next two days.
- Fetch weather data dynamically from WeatherAPI.
- Debounced search to reduce unnecessary API requests.
- Loading indicator while fetching weather data.
- Error message when a location cannot be found or a request fails.
- Responsive design for mobile and desktop screens.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap
- Fetch API
- WeatherAPI

## 🔌 API

This project uses [WeatherAPI](https://www.weatherapi.com/) to retrieve current weather data and forecasts.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/lolaadel/weather-website-project.git
   ```

2. Open the project folder.

3. Configure your own WeatherAPI key for local testing.

4. Open `index.html` in your browser, or use the Live Server extension in VS Code.

## 🔐 API Key Security

For local testing, use your own API key.

**Important:** This project uses a client-side API request. API keys included in frontend JavaScript are visible to visitors. For production applications, API requests should be handled through a backend or secure proxy instead of exposing the key in the browser.
